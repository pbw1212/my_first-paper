# 后期成员观测能把两位发起人定位到多小的范围？

## 任务与评估设计

在真实通信记录上模拟两位源头的扩散，按整批成员遮去前半段加入过程。预测时给出较晚加入成员及其批次顺序，以及事件窗口之前的通信历史。首次加入在同一时刻的成员保留为一批。候选人是窗口前历史名册中所有未在后缀出现的人。每次实际点名的身份和每份候选名单均可与两位模拟真源逐事件核对。

三种输出回答不同的问题。单人点名衡量作答率与已作答事件的准确率。条件名单先点一人，再给另一人的候选，统计两个环节都成功的事件。无条件名单对每个事件直接给出若干候选，分别检查至少一位入选、两位同时入选。只有最后一项用于下文固定 12 人的双源覆盖比较。名单命中不代表两人的身份已唯一确定。

制造企业邮件网和 Dept2 各使用 12 个互不重叠的 14 天窗口。从历史名册内有至少 100 条当期联系的完整窗口中等距取样。前 5 窗拟合，每窗 140 个双源影响均到达可见后缀的事件，简称“双影响组”；中间 3 窗用 240 个此类事件校准；后 4 窗测试，每窗 80 个。另取每个测试窗前 25 个产生合格后缀的事件组成普通组，允许与双影响组重叠。窗口活跃度用于回顾性选窗。每张网络共用一组历史窗口，因此换种子反映的是这些窗口内的模拟波动。

## 能否可靠点名一位源头

每个候选人的特征包含历史活跃度、到可见成员的图距离、近期互动，以及最多六个历史窗口模拟所得的时序可达性。梯度提升树分别学习“此人为真源”和“在固定传播结果下，每一组相容双源都包含此人”。推断只接收历史特征和公开后缀。下表给出两种监督方式在首次时间测试的结果。

| 测试指标 | 制造企业 | Dept2 |
|---|---:|---:|
| 普通真源监督，每次点一人，命中任一真源 | 25/320 | 66/320 |
| 必要身份监督，每次点一人，命中任一真源 | 21/320 | 61/320 |
| 普通监督，只在得分达到校准集第 90 百分位时点名 | 2/26 | 16/37 |
| 在校准集要求至少 15 次作答且准确率达到 80%，应用到测试后的作答数 | 0/320 | 0/320 |
| 恰有一个必要身份的事件中，必要身份模型点中该人的次数 | 8/123 | 17/129 |

“必要身份”是给定一套已实现的接触传播结果、给定双影响筛选条件后的交集。换一次对未使用接触的随机补全，并取两个世界交集，仍有至少一个共同身份的事件分别为 209/320 和 239/320。这个数量描述反事实歧义，不能充当公开预测准确率。

对既有制造企业事件 `company-08-33`，逐对正向回放了全部 7,381 种合法身份组合。满足同一后缀且双源影响均可见的组合恰有三种，即 (23,106)、(58,106)、(83,106)。所以 106 在这个固定传播世界中确实是必要成员。对新的 Dept2 事件 `Dept2-21-0`，10,731 组中有六组相容，六组的交集为空。三个核验样例及完整组合见 [逐对回放](event_replay_check.json)。

在 Dept2，普通监督模型每次先点名，再给第二人的候选名单，平均保留 18.8 名伙伴。先点对的 66 个事件中，有 62 个也覆盖了另一人；分母换成全部 320 个事件，两环节同时成功的比例只有 19.4%。制造企业对应为 25/25、25/320，且伙伴名单平均需 84.9 人。高条件覆盖率很容易掩盖第一步的错误。

## 无条件候选名单与重抽样

名单长度用较早 240 个双影响事件中真源相对名次的经验分位数确定，校准目标为 90%。下表使用普通真源监督的逐人排序。每格是“命中事件数 / 320；平均名单人数”。复测保持训练权重、四个测试窗口、校准阈值，重新抽取源头与传播随机数。

| 目标 | 制造企业首测 | 制造企业复测 | Dept2 首测 | Dept2 复测 |
|---|---:|---:|---:|---:|
| 至少一位入选 | 270/320；35.0 | 254/320；35.0 | 291/320；15.7 | 293/320；15.7 |
| 两位同时入选 | 284/320；70.2 | 275/320；70.1 | 289/320；30.1 | 281/320；30.0 |

首次测试的合法候选平均为 121.0 人和 146.3 人。制造企业需要保留过半候选才能接近 90% 双源覆盖。Dept2 首测在约 30 人时达到 90.3%，复测降到 87.8%。双影响组校准的名单直接用于普通组时，复测两位同时入选分别为 52/100 和 44/100。由此，覆盖率须与筛选条件、名单长度及时间窗口一起报告。

## 同为 12 人，如何选择这 12 人

用最可能的 12 个首源逐一评估条件伙伴分数，其余首源用逐人分数近似。对两个可能的源头顺序取平均，得到对称的组合权重。三种读法可在同一预算下比较。逐人排序直接取前 12；覆盖至少一人时，每一步优先纳入能触及最多尚未覆盖组合的人；覆盖两人时，最大化名单内部组合的权重总和，从三种初值分别做单人替换，取所得最佳名单。最后一项是局部优化。所有权重来自模型评分，未作为真实后验概率解释。

以下每个数字都是**两位真源同时入选**的事件数，每列分母 320。历史时序可达性只按候选人对可见成员的平均历史传播支持排序。三组模拟使用相同窗口，不同随机数。联合优化在看过前两批结果后提出，只在第三批检验。

| 方法 | 制造企业首测 / 复测 / 第三批 | Dept2 首测 / 复测 / 第三批 |
|---|---:|---:|
| 历史时序可达性 | 7 / 11 / 12 | 65 / 63 / 51 |
| 逐人排序 | 15 / 14 / 8 | 116 / 117 / 119 |
| 优先覆盖至少一位 | 15 / 14 / — | 91 / 76 / — |
| 按组合的单人边际权重排序 | — / — / 9 | — / — / 122 |
| 优化名单内部组合权重 | — / — / 10 | — / — / 128 |

Dept2 第三批中，联合优化相较逐人排序额外命中 26 例、丢掉 17 例，净增 9/320；四个窗口净变化为 0、+6、−1、+4。制造企业对应为多 5 例、少 3 例，净增 2/320。两图在普通组第三批的结果分别为 18/100（Dept2）和 1/100（制造企业）。因此可以报告 Dept2 在固定预算上的收益，尤其是学习排序相对可达性基线的收益；额外组合优化的优势较小。

## 固定权重迁移到其他通信网络

将 Dept2 和制造企业的模型分别原样迁移到 Dept1、CollegeMsg，在两个目标网络的最近四个合格窗口生成新模拟事件。两个训练域使用相同目标事件、历史特征计算和 12 人预算，目标网络标签只用于计分。这是本轮方法的免重训迁移测试。Dept1 与 Dept2 来自同一机构，且研究早先已在 Dept1、CollegeMsg 评估过其他方法。

| 12 人名单同时包含两位真源 | Dept1（160 例） | CollegeMsg（139 例） |
|---|---:|---:|
| 历史时序可达性 | 12 | 4 |
| 制造企业训练，逐人排序 | 5 | 0 |
| 制造企业训练，优化名单内部组合权重 | 4 | 0 |
| Dept2 训练，逐人排序 | 41 | 3 |
| Dept2 训练，优化名单内部组合权重 | 42 | 2 |

Dept2 模型迁移到 Dept1 时，联合名单比逐人排序多命中 8 例、丢掉 7 例，净增 1 例。相对历史可达性的净增为 30 例。CollegeMsg 第四个窗口达到设定的 60,000 次抽样上限，仅得到 19 个双影响事件，保留该窗口及全部 139 个合格事件。普通组中，Dept2 联合名单在两个目标网络分别命中 6/60 和 0/60。完整结果见 [Dept1](transfer_Dept1/summary.json) 和 [CollegeMsg](transfer_CollegeMsg/summary.json)。

另用 Dept2 完全相同的 700 个训练事件拟合两种 L2 逻辑回归。两者特征、优化器、每事件的正负样本总权重相同，仅改变输入是否先换算为该事件所有候选中的百分位名次。固定 12 人时，绝对特征与百分位特征的双源命中依次为 Dept2 的 101/320 与 106/320，Dept1 的 19/160 与 27/160，制造企业的 1/320 与 12/320，以及 CollegeMsg 的 3/139 与 6/139。简单的相对名次对照在四张网络都优于其绝对特征版本；CollegeMsg 只有六个正例命中，跨域收益仍需增加独立观察。四张网络的全部名单通过 [逐事件核验](fixed_budget_audit.json)。

### 候选规模能解释多少差距

对同一套 Dept2 逐人排序模型，改成每例保留合法候选的 2%、5%、10%，一律向上取整。下表为 5% 时的核对，基线与模型逐事件使用完全相同的人数。此项用于分析已看到的跨域差异。

| 测试网络 | 平均保留人数 | Dept2 逐人排序，两位同时入选 | 历史时序可达性，两位同时入选 |
|---|---:|---:|---:|
| Dept2 | 7.9 | 57/320（17.8%） | 21/320（6.6%） |
| Dept1 | 15.2 | 48/160（30.0%） | 19/160（11.9%） |
| 制造企业 | 6.5 | 3/320（0.9%） | 2/320（0.6%） |
| CollegeMsg | 91.6 | 44/139（31.7%） | 27/139（19.4%） |

固定 12 人时，这套模型在 Dept1 和 CollegeMsg 的双源覆盖为 25.6% 和 2.2%；固定 5% 时为 30.0% 和 31.7%。因此，两张网络在绝对预算下的落差不能全部归因为模型迁移失效。CollegeMsg 取 10% 时，模型与可达性分别命中 61/139、60/139，平均名单已达 182.8 人。制造企业在相对预算下仍困难。写论文时宜同时给出绝对人数、相对预算和对照方法的覆盖率；精确点名须另行评估。[CollegeMsg 全部预算](transfer_CollegeMsg/relative_budget.json) · [Dept1 全部预算](transfer_Dept1/relative_budget.json)

## 复现

在项目根目录运行如下命令。每张开发网络的目录内保存模型、窗口边界、公开观测、单独的模拟真值、逐事件输出，以及按窗口汇总的分子分母。两次新抽样均检查随机种子与先前批次不重合。复测代码也重新计算了校准规则，并核对首批名单的指标与原始汇总逐项相同。

```powershell
foreach ($network in 'company','Dept2') {
    python scripts/partial_source_identification.py $network
    python scripts/partial_source_lists.py $network
    python scripts/replicate_partial_lists.py $network
    python scripts/joint_source_shortlist.py $network
}
python scripts/check_partial_source_example.py
foreach ($network in 'Dept1','CollegeMsg') {
    python scripts/transfer_joint_shortlist.py $network
}
python scripts/relative_source_ranking.py fit
foreach ($network in 'Dept2','company','Dept1','CollegeMsg') {
    python scripts/relative_source_ranking.py $network
    python scripts/relative_budget_check.py $network
}
python scripts/audit_fixed_shortlists.py
```

逐事件及逐窗结果可从 [Dept2 重抽样](Dept2/replication.json)、[企业重抽样](company/replication.json)、[Dept2 联合优化](Dept2/joint12_summary.json) 和 [企业联合优化](company/joint12_summary.json) 进入。
